# 录音时光机
一个能够在后台录音，并且缓存在内存中的应用。
默认缓存最近5分钟的内容，可以在启动录音之前先调整缓存时长。
回到应用中点击导出缓存便可以将缓存中的内容导出至文件中。
类似于 NVIDIA App 中的“即时回放”功能，但是在安卓端针对音频。
缓存会导出至 `/sdcard/录音时光机/` 文件夹中。

# 关于项目
其实这算是一个练手项目，这之前我没有接触过 Java。绝大多数代码还是 AI 写的，主要是理解每一行代码是干什么用的，以及 Java 的代码都有什么结构。

至于为什么要写这一个项目，主要还是因为自己的同学和室友随时都有可能会嗷嗷叫，各种叫法都有。于是我想把这些录下来做为他们的黑历史。可我又不能每时每刻都录着音，不然就会产生动辄几个小时的录音文件，结果几乎没有我想要的内容。于是我就在想，手机上有没有针对音频的、类似于及时回放的功能的软件？可无论怎么搜索都搜不到。于是我就萌生了“自己写一个这种软件”的想法。可我完全没有 Java 经验，于是这里面的绝大多数代码都是 AI 生成的。
